# Neon Prism Breaker

Versão moderna do clássico *Brick Breaker* desenvolvida com JavaScript nativo e sem dependências externas, segundo princípios de Engenharia de Software (Máquina de Estados, Barramento de Eventos Observer, Passo de Física Fixo a 120 Hz e Design Orientado a Dados).

## Como Executar
1. Extrair o arquivo ZIP.
2. Abrir `index.html` diretamente num navegador moderno; não é necessário instalar Node.js nem iniciar um servidor.
3. Jogar com rato, teclado (`←` / `→` ou `A` / `D`) e `Espaço`.
